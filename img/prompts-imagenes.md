# Prompts para generar imágenes (ChatGPT / DALL-E)

Estilo default: ilustración vectorial plana, SaaS corporativo (Stripe/Notion/Linear),
paleta navy #1a3a5e + cyan #00d4ff + blanco. Sin texto/letras en la imagen.

Guardar los PNG resultantes en esta misma carpeta (`img/`) con estos nombres exactos.

## Si no te gusta el estilo default

Cambia la primera línea de cada prompt por una de estas variantes antes de pegarlo:

- **3D isométrico suave**: `Soft 3D isometric illustration, pastel shading, blender-style render...`
- **Foto-realista con overlay UI**: `Realistic photograph, shallow depth of field, with a clean UI overlay mockup...`
